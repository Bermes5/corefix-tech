CLIMASUL AR CONDICIONADO — SITE DEMONSTRATIVO

Arquivos:
- index.html
- styles.css
- script.js
- assets/favicon.svg
- assets/og-climasul.svg

Como abrir:
1. Abra o arquivo index.html no navegador.
2. Para publicar, envie a pasta inteira para sua hospedagem.

Configuração principal:
- O número do WhatsApp fica em UMA única constante no topo de script.js:
  SITE_CONFIG.whatsappNumber
- Use somente dígitos, incluindo 55 + DDD + número.

Antes de publicar comercialmente, substitua:
- telefone, WhatsApp, e-mail e endereço;
- regiões atendidas;
- horários;
- métricas (+500, 5 anos etc.);
- avaliações demonstrativas;
- imagens demonstrativas;
- URL canônica e dados Open Graph;
- Schema.org/JSON-LD;
- links de redes sociais e política de privacidade.

Observação sobre imagens:
As fotos demonstrativas são carregadas remotamente do Pexels para manter esta entrega leve.
Para uma versão final 100% autocontida/offline, baixe as imagens autorizadas do cliente,
otimize em WebP/AVIF e troque os atributos src no index.html por caminhos locais em assets/.
